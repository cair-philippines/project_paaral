## Coding Standards

### Field Naming Convention

**Database/Data Layer:** snake_case
- `school_id`, `slots_available`, `tuition_annual`, `distance_km`
- Mirrors BigQuery schema conventions

**Display Layer:** Human-readable via mapping
- Map via `constants/labels.js`: `{ tuition_annual: "Annual Tuition" }`
- Never mix naming conventions in the same file

**File exports from data pipeline:**
- `schools.geojson` — all school types (public ES + public JHS + private JHS + private ESC JHS)
- `students.json` — synthetic students with ranked ESC preferences
- `flows.json` — origin-destination pairs

### School Type Taxonomy

```javascript
const SCHOOL_TYPES = {
  public_es:        "Public Elementary",
  public_jhs:       "Public JHS",
  private_jhs:      "Private JHS (No ESC)",
  private_jhs_esc:  "Private JHS (With ESC)",
};
```

**Congestion metrics apply to:** All JHS types (`public_jhs`, `private_jhs`, `private_jhs_esc`)
**ESC slot metrics apply to:** `private_jhs_esc` only

### Region & Subsidy Taxonomy

Mockup scope is **NCR + Region IV-A only.**

```javascript
// Geographic region (two values only)
const REGIONS = {
  ncr: "National Capital Region (NCR)",
  iva: "Region IV-A (CALABARZON)",
};

// City type drives the ESC subsidy tier (three values only)
const CITY_TYPES = {
  ncr:   { label: "NCR",                   subsidy: 13000 },
  huc:   { label: "Highly Urbanized City", subsidy: 11000 },
  other: { label: "Other",                 subsidy: 9000  },
};
```

**How `city_type` is assigned:**
- `ncr` — all schools located in NCR (regardless of PSA HUC status)
- `huc` — schools in Lucena City only (sole Region IV-A HUC per 2025 PSA list)
- `other` — all remaining Region IV-A schools (Cavite, Laguna, Batangas, Rizal, Quezon municipalities)

**HUC classification source:** `public/reference/huc_list.png` (2025 PSA List of HUCs)

### GeoJSON Schema

All schools are in a single `schools.geojson` FeatureCollection.

**Common fields (all school types):**
```json
{
  "school_id":        "300133",
  "name":             "Angeles National High School",
  "school_type":      "public_jhs",
  "region":           "ncr",
  "city":             "Navotas",
  "city_type":        "ncr",
  "province":         "NCR Third District",
  "barangay":         "Bangculasi",
  "num_classrooms":   28,
  "seats":            1120,
  "enrollment":       1316,
  "congestion_ratio": 47.0
}
```

**Additional fields by type:**
- `private_jhs` / `private_jhs_esc`: + `tuition_annual`
- `private_jhs_esc`: + `slots_total`, `slots_available`

**Constraint enforced:** `slots_total ≤ seats` for all ESC schools.

**Seats calculation:** `seats = num_classrooms × 40` (standard DepEd classroom size).

### Congestion Definition

Two modes, user-toggleable in the FilterBar:

| Mode | Congested when |
|---|---|
| `seats` | `enrollment > seats` |
| `ratio` | `congestion_ratio > threshold` (threshold is a slider, 25–60) |

Private schools can be congested in both modes. Synthetic enrollment ranges:
- Public JHS: ratio = rand(40–55 NCR, 30–50 IVA) → almost always above seats
- Private (No ESC): enrollment = rand(65–110%) of seats → ~23% congested
- Private (ESC): base enrollment = rand(65–100%) + ESC slots used → ~13% congested

### Data Sources

**Real school data (names, coordinates, geography):**
- `github.com/cair-philippines/project-school-coordinates`
- Files: `data/gold/public_school_coordinates.csv`, `data/gold/private_school_coordinates.csv`
- Cached at `/tmp/` by `scripts/generate_data.js`; re-downloaded if missing

**Synthetic data (numeric fields):** Generated by `scripts/generate_data.js`.

### Data Processing Rules

1. **No direct database access in mockup**
   - Load from static files in `public/data/`
   - Data generation scripts stay in `scripts/`

2. **Real school IDs use DepEd LIS IDs (public) and BEIS IDs (private)** — not the old synthetic `JHS_PUB_001` format

3. **Never do a deep search of files.** Load the directory schema then infer from that.

4. **Before running code implementations, always confirm with the user first the objective of the code.**
