name: LRN verification purpose
description: Clarification on what the LRN verification step is for in the student view
type: feedback
---

LRN verification in the student portal is a pure registry identity check — "is this LRN in DepEd's database?" — not an ESC eligibility gate. Do not conflate it with ESC eligibility logic or subsidy tiers.

**Why:** The user corrected an attempt to layer ESC eligibility (subsidy tiers, origin school congestion) onto the LRN step. That context may be surfaced elsewhere in the app, but the LRN check is only about confirming the learner exists in the system.

**How to apply:** When touching the LRN verification flow, keep the concern narrow: input format, registry lookup simulation, and identity confirmation feedback only.
